# luca-core

Open source data layer for LucaVault.

## Packages

- `@luca-core/database` — Schema Drizzle, migrations, tipos TypeScript
- `@luca-core/data-access` — Repositorios y queries
- `@luca-core/encryption` — Cifrado en reposo, key management
- `@luca-core/permissions` — Roles y políticas de acceso

## Why open source?

LucaVault's privacy promise is verifiable. This package contains all code
that handles how data is stored and protected. Clients can audit it.
